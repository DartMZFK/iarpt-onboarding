# Серверный генератор PDF

Боевой `POST /api/result` обслуживает systemd-сервис `iarpt-card.service` на
`card.iarpt.ru`. Рабочий каталог сервера: `/opt/iarpt-card`, Node.js слушает
`127.0.0.1:3077`, наружу запросы проксирует Nginx.

`iarpt-quiz.html` является единственным исходником вопросов, профилирования и
`buildPdf`. `build-engine.js` извлекает из него исполняемый снимок
`quiz/engine.js`. `sync-quiz.sh` скачивает актуальный HTML из `main`, проверяет
обязательные маркеры, собирает новый снимок и только затем атомарно заменяет оба
файла. `server.js` проверяет время изменения снимка перед созданием результата и
подхватывает обновление без перезапуска процесса.

## Проверка локально

```sh
cd server
npm ci
npm run check
npm test
```

## Деплой

Перед заменой файлов сделайте резервные копии `server.js`, `build-engine.js` и
`sync-quiz.sh`. Затем установите файлы в `/opt/iarpt-card`, сгенерируйте
`/opt/iarpt-card/quiz/engine.js`, выполните `node --check`, перезапустите
`iarpt-card.service` и проверьте `/health`. Секреты остаются только в
`/etc/iarpt-card.env` и в репозиторий не копируются.
