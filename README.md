# Онбординг «Карта вашего Телохранителя» — iARPT

## Что это
Одностраничное веб-приложение: 21 диагностический вопрос → именной PDF (8 страниц), собранный из ответов прямо в браузере.
Сервер не нужен. Ничего никуда не отправляется.

## Как разместить
1. Положите `index.html` на любой хостинг (GitHub Pages, Tilda «свой код», Vercel, Netlify, обычный nginx).
   Файл самодостаточный: логотип, шрифты для PDF и все тексты внутри.
2. Единственная внешняя зависимость — библиотека jsPDF, подгружается с cdnjs:
   `https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js`
   Если хостинг без доступа к CDN — скачайте файл и положите рядом, поменяв `src` в `<head>`.
3. Шрифты интерфейса (Manrope, Playfair Display) грузятся с Google Fonts. Без них страница работает на системных шрифтах.

`index.html` начинается с `<title>` — в нём нет `<!DOCTYPE>/<html>/<head>/<body>`,
потому что он собирался для платформы, которая оборачивает документ сама.
Для обычного хостинга оберните так (или используйте `index_standalone.html` из этой папки):

```html
<!DOCTYPE html><html lang="ru"><head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1">
…содержимое index.html…
</body></html>
```

## Как работает выдача PDF
Кнопка «Скачать мою карту (PDF)» генерирует файл `Карта_Телохранителя_<Имя>.pdf` и отдаёт его стандартной загрузкой браузера.
На платформе claude.ai используется её механизм сохранения; на обычном хостинге — `<a download>`. Оба пути уже в коде.

## Переменные результата (для связки с ботом)
Функция `scores()` возвращает: `S` (сегмент), `G` (0–100) и `Gl` (уровень 1–4), `T` и `T2` (тип саботажа, второй при смешанном),
`B` (соматическая подпись), `V` и `Vstrong` (скрытая выгода), `F` (фаза), `R` (темп), `S2`/`conflict` (расхождение сегмента и тела), `C` (занятость).
Функция `token(s)` сворачивает профиль в короткий код вида `MNW_P3B4` — его удобно передавать в deep-link бота (`t.me/<bot>?start=<token>`).
Расшифровка кода — в `Спецификация_онбординга.docx`, раздел 7.

## Где править
- `src/app.html` — разметка, стили, вопросы (массив `QS`), логика подсчёта, сборка PDF (`buildPdf`).
- `src/pdfcontent.js` — все тексты PDF по модулям.
- `src/build.js` — собирает `index.html` из `app.html`, встраивая шрифты и картинки: `node build.js`.
- `src/fonts.json`, `src/imgs.json` — шрифты (DejaVu, подмножество кириллицы) и логотип в base64.
