# Онбординг «Карта вашего Телохранителя» — iARPT

## Что это
Одностраничное веб-приложение: 21 диагностический вопрос → именной PDF (8 страниц), собранный из ответов прямо в браузере.
Сервер не нужен. Ничего никуда не отправляется.

## Дизайн
Оформление приведено к фирменному стилю [iarpt.ru](https://iarpt.ru/):

| | |
|---|---|
| Заголовки | Cormorant SC 600/700, uppercase, line-height ≈ 1.0 |
| Текст и интерфейс | Inter Tight 300–700 |
| Акцент | `#BC2C2C` |
| Текст | `#000` / `#323232` / `#5C5C5C` / `#828282` |
| Фоны | `#FFFFFF`, `#F1F1F1`, красный `#BC2C2C` |
| Кнопки | радиус 30px, белым по красному |

Лендинг адаптивный от 320px до 1440px+: герой на красном в одну колонку на мобильном
и в две от 900px, блок «что вы узнаете» — 1 / 2 / 3 колонки (760px, 1040px),
типографика на `clamp()`, фиксированных ширин нет.

## Файлы сборки

| Файл | Куда |
|---|---|
| `index.html` | Обычный хостинг: GitHub Pages, Vercel, Netlify, nginx. Самодостаточный. |
| `index_tilda.html` | Тот же код без своего сброса `html/body` — если вставлять целиком в блок Тильды. |
| `tilda-embed.html` | Сниппет для блока T123: квиз встроен в страницу, iframe + автовысота. |
| `tilda-zero-button.html` | Сниппет для блока T123: квиз открывается поверх страницы по кнопке из зеро-блока. |

Собирается из `src/`: `cd src && node build.js` — пишет оба файла в корень.

## Как разместить на Тильде

### Вариант 1 — iframe (рекомендуется)
`index_tilda.html` весит ~600 КБ (в него вшиты шрифты для PDF и картинки в base64).
Поле «HTML-код» в Тильде на такой объём не рассчитано, поэтому:

1. Положите `index.html` на хостинг. Проще всего оставить на GitHub Pages:
   `https://aleksei1999.github.io/iarpt-onboarding/index.html`
2. Добавьте на страницу блок **T123 «HTML-код»** и вставьте содержимое `tilda-embed.html`.
3. Если файл лежит по другому адресу — поправьте `src` у `<iframe>`. Параметр `?embed=1` обязателен.

Что даёт `?embed=1`: приложение перестаёт растягивать экраны на всю высоту окна, меряет
свою высоту и отдаёт её родителю через `postMessage`. Блок подстраивается под контент,
внутренней полосы прокрутки нет, переход между экранами прокручивает страницу Тильды
к началу блока. Стили Тильды на приложение не влияют вообще — оно в отдельном документе.

### Вариант 1б — свой стартовый экран в зеро-блоке, квиз по кнопке
Когда первый экран вы рисуете сами в Zero Block, а кнопка должна открывать анкету:

1. Кнопке в зеро-блоке поставьте ссылку `#onbquiz` (либо задайте ей класс `onbquiz`).
   Кнопок может быть сколько угодно, хоть в разных блоках.
2. Добавьте на страницу один блок **T123** и вставьте `tilda-zero-button.html`.
   Место блока неважно — окно открывается поверх всего.

Квиз открывается модальным окном: на мобильном на весь экран, на десктопе карточкой 720px.
Закрывается крестиком, по Esc, кликом по фону и стрелкой «назад» с первого экрана анкеты.
Файл приложения (~600 КБ) не грузится, пока кнопку не нажали. Прогресс сохраняется:
закрыли и открыли снова — продолжаете с того же вопроса. Прокрутка страницы под окном
заблокирована и возвращается на прежнее место после закрытия.

Ключ здесь — параметр `?start=welcome` в адресе iframe: приложение пропускает свой
встроенный лендинг и начинает с анкеты. Тот же параметр можно дописать и в `tilda-embed.html`
(`&start=welcome`), если квиз нужен не окном, а встроенным в страницу блоком под зеро-блоком.

### Вариант 2 — код прямо в блок
Если Тильда примет объём: вставьте `index_tilda.html` целиком в блок T123.
Всё оформление заскоуплено под `#iarpt-onb`, скрипт ищет элементы только внутри своей
обёртки — чужую разметку страницы не заденет и на чужие `id` не наткнётся.

## Внешние зависимости
- **jsPDF** с cdnjs (с `integrity`/SRI). Без доступа к CDN — скачайте файл, положите рядом
  и поменяйте `src` в `src/app.html`, убрав атрибут `integrity`.
- **Google Fonts** (Inter Tight, Cormorant SC). Без них страница работает на системных шрифтах.

Шрифты самого PDF вшиты в файл и от сети не зависят.

## Как работает выдача PDF
Кнопка «Скачать мою карту (PDF)» генерирует файл `Карта_Телохранителя_<Имя>.pdf`
и отдаёт его обычной загрузкой браузера (`<a download>`). Работает и внутри iframe.

## Переменные результата (для связки с ботом)
Функция `scores()` возвращает: `S` (сегмент), `G` (0–100) и `Gl` (уровень 1–4), `T` и `T2` (тип саботажа, второй при смешанном),
`B` (соматическая подпись), `V` и `Vstrong` (скрытая выгода), `F` (фаза), `R` (темп), `S2`/`conflict` (расхождение сегмента и тела), `C` (занятость).
Функция `token(s)` сворачивает профиль в короткий код вида `MNW_P3B4` — его удобно передавать в deep-link бота (`t.me/<bot>?start=<token>`).
Расшифровка кода — в `Спецификация_онбординга.docx`, раздел 7.

## Где править
- `src/app.html` — разметка, стили, вопросы (массив `QS`), логика подсчёта, сборка PDF (`buildPdf`).
- `src/pdfcontent.js` — все тексты PDF по модулям.
- `src/build.js` — сборка.
- `src/fonts.json`, `src/imgs.json` — шрифты (DejaVu, подмножество кириллицы) и логотип в base64.
